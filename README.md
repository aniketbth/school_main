# School ERP Setup

This project contains a PHP + MySQLi school management system scaffold for a school or coaching center.

Stack:
- PHP 8+
- MySQLi prepared statements
- Bootstrap 5
- jQuery + AJAX
- MySQL

Setup steps:
1. Create a MySQL database named `school_main`.
2. Import `database.sql`.
3. Update database credentials in `config/db.php` if needed.
4. Run the site from your web root (`htdocs` / `public_html`).
5. Log in using demo accounts:
   - admin@school.com / password
   - principal@school.com / password
   - teacher@school.com / password
   - student@school.com / password
   - parent@school.com / password
   - accountant@school.com / password
   - librarian@school.com / password
   - reception@school.com / password

Notes:
- Default login is enabled for demo use.
- You can add real school data after the initial setup.
